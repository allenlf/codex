Simple Snake Game
=================

This repository contains a simple terminal-based snake game written in Python using the curses module.

To start the game:

    python snake_game.py

Use the arrow keys to move the snake. Eat the food 'O' to grow. Avoid running into the walls or yourself. Your current score is shown at the top of the screen and increases with each piece of food eaten.

This game runs in the terminal and requires a Unix-like environment with curses support.
